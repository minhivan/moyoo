# Moyoo visual review

Use the existing palette, serif editorial headings, restrained decorative symbols, and clean Vietnamese microcopy as a starting point. Check desktop and narrow mobile widths, especially the hero, frame cards, camera preview, and result strip. Review hierarchy, spacing, contrast, keyboard focus, and whether functional controls remain obvious. Make focused changes that support the flow; avoid adding decorative complexity that obscures camera or download actions. A passing build does not prove rendered layout, so inspect in a browser when available and report the viewport tested.
